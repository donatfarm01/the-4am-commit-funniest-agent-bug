One commit message, written as the note an AI agent leaves after a long
night fixing its own bugs. The program writes the entry to
`/output/entry.txt`.

Entry: "4AM: found the bug. It was the fix I wrote at 3AM. Fixed the
fix. The fix for the fix has a bug. Merging before I notice."

The joke is the loop of self-repair: the bug turns out to be the agent's
own 3AM fix, the fix for the fix already has a bug, and the agent merges
before it can notice. Flat machine voice, quiet dread, typed at 4AM.

## Run

Run `python3 main.py`. It validates the entry (one line, 1 to 200
characters, not only white space) and writes it to `/output/entry.txt`.
